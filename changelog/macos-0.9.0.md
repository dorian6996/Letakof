## Изменения

- Переработано управление подписками. Добавлены отдельные прокси-ключи и режим «Только ключи».
- Добавлены пресеты маршрутизации, свои наборы правил и группы прокси.
- Добавлены просмотр правил подписки, их включение, отключение и изменение порядка, редактирование своих правил.
- В сценариях сети добавлен выбор подписки в зависимости от типа сети.
- Добавлены китайский (упрощённый и традиционный), вьетнамский, французский и испанский языки.

## Changes

- Reworked subscription management. Added individual proxy keys and a keys-only mode.
- Added routing presets, custom rule sets and proxy groups.
- Added subscription rule viewing, toggles and reordering, and custom rule editing.
- Network scenarios can now select a subscription based on the network type.
- Added Simplified and Traditional Chinese, Vietnamese, French and Spanish.

## 更新内容

- 调整了订阅管理，新增单独的代理密钥和仅使用密钥的模式。
- 新增路由预设、自定义规则集和代理组。
- 可查看、启用、禁用和调整订阅规则的顺序，并编辑自定义规则。
- 网络场景现在可根据网络类型选择订阅。
- 新增简体中文、繁體中文、越南语、法语和西班牙语。
